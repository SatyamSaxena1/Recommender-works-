# Recommender-works-\n\nThis branch switches the notebook to download data using KaggleHub instead of local file paths.\n\n## What's changed\n- Adds KaggleHub-based dataset download of `rounakbanik/the-movies-dataset`.\n- Builds a `movies` table by joining `links.csv` to `movies_metadata.csv` to get titles for MovieLens `movieId`.\n- Uses `ratings_small.csv` by default for faster demos (you can switch to `ratings.csv`).\n- Adds `requirements.txt` for reproducible setup.\n\n## Run locally\n1. Create and activate a Python 3.9+ environment.\n2. Install deps:\n\n```pwsh
pip install -r requirements.txt
```\n\n3. Open the notebook `This one works.ipynb` and run all cells. The first cell will install `kagglehub` if missing and download the dataset to your local KaggleHub cache.\n\n### Switch to full ratings (optional)\nIn the first cell, change `ratings_small.csv` to `ratings.csv` for the full dataset. Note: it's much larger and will be slower.\n
